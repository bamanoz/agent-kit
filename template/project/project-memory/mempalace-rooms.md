# Комнаты Mempalace

Крыло проекта: `{{WING}}`. Git-файлы являются источником точных сведений.
Комнаты содержат краткий контекст, причины решений, блокеры и ссылки на Git.

## Общие комнаты

| Комната | Назначение |
| --- | --- |
| `implementation-overview` | Общий статус и текущий этап |
| `implementation-baseline` | Краткое отражение `baseline.yaml` |
| `implementation-change-control` | Активные `CHG-*`, отмененные решения и переходы |
| `implementation-contracts` | Версии контрактов и ссылки на точные схемы |
| `implementation-open-questions` | Активные вопросы и владельцы ответа |
| `implementation-environments` | Несекретные версии и готовность сред |
| `implementation-test-evidence` | Результаты тестов и ограничения evidence |

## Изменение границ компонентов

Комнаты не определяют архитектуру и не блокируют ее изменение. Если новая
ревизия объединяет или разделяет компоненты:

1. Старые комнаты сохраняются как исторические.
2. В них добавляется запись `SUPERSEDED` со ссылкой на `CHG-*`, новую ревизию
   и новые комнаты.
3. Для новых границ создаются новые комнаты.
4. Общие комнаты обновляются ссылками на новый Git-baseline.

Нельзя переименовывать старую комнату так, чтобы потерялась связь с прежней
ревизией архитектуры.
