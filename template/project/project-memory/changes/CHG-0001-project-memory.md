# CHG-0001: Введение системы проектной памяти

Статус: `IMPLEMENTED`

Дата: {{DATE}}

Источник: решение проекта

Исходная ревизия: `—`

Целевая ревизия: `ARCH-0001`

## Причина

Работа выполняется агентами в нескольких сессиях. Решения, границы
компонентов и требования могут меняться; без версионируемой памяти агенты
теряют контекст и причины принятых решений.

## Изменение

Введены независимые проектный, реализационный и эксплуатационный baseline,
версионируемые ревизии архитектуры, ADR, записи существенных изменений,
реестр открытых вопросов и регламент синхронизации с Mempalace (крыло
`{{WING}}`). Установлено комплектом agent-kit {{KIT_VERSION}}.

## Анализ влияния

| Область | Влияние | Требуемое действие |
| --- | --- | --- |
| Компоненты | Начальная модель получила ID `ARCH-0001` | Новые границы оформлять новой ревизией |
| Контракты | Контракты связываются с ревизией и ADR | Размещать в `contracts/` |
| Данные и миграции | Отсутствуют | Добавлять анализ при появлении кода |
| Информационная безопасность | Запрещено хранение секретов в памяти | Следовать корневому `AGENTS.md` |
| Тесты и приемка | Evidence связывается с baseline | Сохранять ссылки на тесты и отчеты |
| Развертывание | Ведется отдельно от реализации | Обновлять только после установки |
| Сроки и стоимость | Не изменены | Анализировать в последующих `CHG-*` |

## Переход

Агенты работают по `session-protocol.md`; существенные изменения проходят
через новый `CHG-*`, ADR и обновление соответствующего baseline.
