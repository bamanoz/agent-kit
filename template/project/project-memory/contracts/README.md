# Формальные контракты

Здесь размещаются или индексируются точные машинные контракты проекта:

- OpenAPI и AsyncAPI внешних и внутренних интерфейсов;
- JSON Schema, XSD, protobuf сообщений и команд;
- перечисления кодов ошибок и состояний;
- положительные и отрицательные примеры без чувствительных данных.

Комплект контрактов указывает редакцию, статус жизненного цикла, ревизию
архитектуры, связанный ADR, целевые компоненты и контрактные тесты.
Изменение контракта сопровождается `CHG-*` и обновлением тестов.
